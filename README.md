# 🚀 Fede Nowback — Plataforma Web & Campus Oficial

Sitio web oficial, landing pages de alta conversión, campus virtual y comunidad para **Fede Nowback** (Estratega de Contenidos, Mentor de Creadores y Speaker).

- **Dominio Producción:** `https://fedenowback.com.ar` (Servidor Ploi `errante` - `72.61.34.92`)
- **Servidor Dev:** `http://localhost:8015/` (Servidor Central Antigravity `72.62.107.109`)
- **Repositorio GitHub:** `https://github.com/elbuje/fedenowback` (`main`, `dev`)
- **Stack:** PHP 8.x nativo modular, MySQL (PDO), CSS Vanilla responsivo, Schema.org JSON-LD.

---

## 🏃 Cómo levantar el servidor de desarrollo local

```bash
# Iniciar servidor PHP en puerto 8015
php -S 0.0.0.0:8015 -t website-php/public website-php/public/index.php
```

Auto-inicio configurado en `/home/mfmujic/start-dev-servers.sh`.
